# Problem Solving

Problem-solving content is organized by pattern first.

The goal is not to collect disconnected solutions. Each problem should strengthen pattern recognition and recall.

## Structure

```text
Pattern
  -> Variant
      -> Representative Problems
```

## What Pattern Pages Should Teach

- Recognition signals
- Mental model
- Core algorithm
- Visual representation
- Common variants
- Complexity characteristics
- Common mistakes
- Canonical problems
- Related patterns

Start with [Patterns](patterns/index.md).
